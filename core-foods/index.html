육지거북 먹이 핵심 9종

“먹여도 되나?”만 보지 않고 급여 수준 → 적용 범위 → 근거 수준 → 한계 순서로 확인한다. 아래 9종은 국내 사육자가 자주 접하는 먹이를 빠르게 상세 근거 페이지로 연결하기 위한 묶음이며, 9종만으로 식단을 구성하라는 뜻은 아니다.

69종 전체 검색오늘 식단 후보 보기
30초 읽는 법
① 급여 수준혼합식 활용인지, 제한적·보조적 급여인지 먼저 본다.
② 적용 범위지중해 Testudo 직접 근거인지, 더 넓은 육지거북 일반 근거인지 구분한다.
③ 근거와 한계야생 섭식 관찰·사육자료·식물 동정 한계를 상세페이지에서 확인한다.

치커리Cichorium intybus제한적으로 혼합 급여지중해 Testudo 직접 섭식 근거까지 상세 확인근대Beta vulgaris가끔 보조적으로 급여육지거북 일반 근거와 제한점을 상세 확인콘샐러드(램스레터스)Valerianella locusta가끔 보조적으로 급여일반 보조 근거의 적용 범위를 상세 확인민들레Taraxacum spp.혼합식으로 활용 가능지중해 Testudo 근거와 속 수준 동정 범위를 함께 확인질경이Plantago spp.혼합식으로 활용 가능혼합식 근거와 속 수준 적용 범위를 상세 확인뽕잎Morus spp.가끔 보조적으로 급여일반 보조 근거와 근거 수준을 상세 확인아욱Malva spp.판정 보류국내 유통명만으로 종을 확정할 수 없어 동정부터 확인로메인Lactuca sativa var. longifolia가끔 보조적으로 급여지중해 Testudo 적용 근거와 한계를 상세 확인엔다이브Cichorium endivia상세 판정 확인치커리와 이름이 비슷해도 별도 식물로 구분해 확인
이 페이지가 하지 않는 것

이 9종의 순위를 매기거나 “완벽한 식단”을 제시하지 않는다. 야생에서 먹었다는 관찰은 사육 배합률을 뜻하지 않으며, 사람용 영양자료만으로 육지거북 급여 판정을 확정하지 않는다. 사진과 유통명만으로 식물 종도 확정하지 않는다.
