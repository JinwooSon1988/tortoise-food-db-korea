# 한국어 근거 표시 개선 (2026-10-16)

## 문제
한국어 상세 페이지 생성기(`scripts/generate_static_pages.py`)는 근거 기록의 영어 필드를 정해진 문장 패턴으로만 한국어로 바꾼다. 패턴에 없는 영어 문장은 모든 카드에 똑같은 일반 문구로 대신 표시했다. 영어 페이지는 같은 카드에 원래 내용을 보여 줬기 때문에, 한국어 사용자가 받는 정보가 더 적었다.

PR #315 머리(`af286331`)에서 센 결과는 다음과 같다.

| 카드 칸 | 일반 문구로 대신 표시된 수 |
|---|---|
| 핵심 내용 요약 (`supports`) | 84 |
| 식물 범위 (`plant_taxon`) | 4 — 파프리카, 블랙베리잎, 토마토 2. 검증 보고서의 "6건" 중 쑥갓·애호박 2건은 검사 스크립트의 오탐이었다. 학명 바로 뒤에 한국어 조사가 붙은 경우(`coronarium은`)를 인식하지 못했다. |
| 식물 부위·상태 (`plant_part_state`) | 89 |
| 말할 수 없는 내용 (`does_not_support`) | 230 |
| 원자료가 다룬 동물 (`animal_taxon`) | 5 |

## 수정
- `data/i18n/ko/evidence_text_ko.json`(신규): 영어 원문 312개를 한국어로 옮긴 표다. 필드별로 영어 원문과 한국어를 짝지었다.
  - 영어 문장에 없는 내용은 덧붙이지 않았다.
  - 학명·수치·단위는 원문 그대로 두었다.
  - 영어 일반명은 따옴표로 표시했다(예: ‘curly dock’).
- 생성기 5개 표시 함수는 이 표에 같은 영어 원문이 있을 때만 한국어를 쓴다. 기록의 영어가 바뀌면 그 항목은 쓰이지 않고 QA가 실패한다.
- 결과: 한국어 페이지 156쪽에서 일반 문구가 0개가 됐다. 영어 페이지·판정·등급·근거 기록은 바뀌지 않았다.
- `data/korean_copy_intentional_english_v1.json`에 분석법 약어(NMR, GC-MS, LC-MS/MS 등), 학술지명 Food Control, 품종명 Festival을 추가했다.

   - 영어의 모든 수치와 학명이 한국어에 남아 있다.
