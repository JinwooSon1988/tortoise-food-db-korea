# 거북밥 공개 운영 릴리스 게이트 v5.5

## 목적
블로그 유입을 본격화하기 전에 공개 사이트가 실제 사용자를 받을 준비가 되었는지 판정한다.

## 현재 기준선
- 공개 저장소: JinwooSon1988/tortoise-food-db-korea
- GitHub Pages 프로젝트 사이트
- Google Search Console 소유권 확인 완료
- 핵심 URL 수동 색인 요청 시작
- sitemap.xml 제출은 Search Console에서 일시적으로 `사이트맵을 읽을 수 없음` 상태이므로 재확인 필요

## P0 — 유입 전에 반드시 통과
- [ ] 공개 홈이 200 응답하고 모바일에서 핵심 검색 UI가 보인다.
- [ ] 한국어 먹이명 검색이 69종 공개 계약과 일치한다.
- [ ] 검색 결과에서 판정·적용범위·근거 요약·상세페이지 이동이 작동한다.
- [ ] 대표 상세페이지(chicory, dandelion, plantain, lambs_lettuce)가 공개되고 canonical/robots/index 메타가 일치한다.
- [ ] `오늘 뭐 먹일까?`가 프로필 종 범위를 반영하고 금지 판정을 후보에서 제외한다.
- [ ] 프로필 생성/선택/수정과 최근 7일 기록이 브라우저 저장 후 재접속에서도 유지된다.
- [ ] JSON 백업→초기화/다른 상태→복원 왕복이 데이터 손실 없이 작동한다.
- [ ] 모바일 360px 폭에서 검색·상세·Today·프로필·기록의 핵심 CTA가 가려지지 않는다.
- [ ] 오프라인 페이지와 service worker가 설치 실패 시에도 온라인 사용을 막지 않는다.
- [ ] sitemap.xml이 Search Console에서 읽히고 발견 URL 수가 0보다 커진다. 실패가 지속되면 실제 HTTP 응답/리디렉션/Content-Type을 조사한다.

## P1 — 공개 직후 추적
- [ ] 홈과 우선 상세페이지가 Google URL 검사에서 발견/색인 상태로 전환되는지 확인한다.
- [ ] Search Console 색인·크롤링 오류를 기록한다.
- [ ] 네이버 검색 유입용 글의 CTA는 DB 판정보다 강한 표현을 사용하지 않는다.
- [ ] 첫 사용자 피드백은 기능 오류/이해 실패/검색 실패로 분류해 수정 우선순위를 정한다.

## 출시 판정
P0에 미확인 항목이 있으면 `유입 확대 전 검증 중`으로 본다. P0가 모두 통과하고 치명적 오류가 없을 때만 `유입 확대 가능`으로 전환한다.

## 변경 원칙
운영 점검에서 발견된 문제만 별도 feature branch와 PR로 수정한다. 근거 없이 판정 강도, 급여 비율, 식물 동정을 변경하지 않는다.
