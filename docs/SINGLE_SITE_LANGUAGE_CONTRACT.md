# 거북밥 단일 사이트 언어 전환 계약 (필수)

## 변경 불가 요구사항
- 한국어가 유일한 콘텐츠·판정 기준이다. 영어는 동일한 식물·판정·근거·영양정보를 번역해 표시한다.
- 언어 전환은 현재 식물과 화면 상태를 유지한다. 식물 ID, 등급, 숫자, 출처 URL, 이미지, DOM 섹션 구조가 언어에 따라 달라지면 실패다.
- 한국어/영어를 별도 판정 데이터나 별도 제품으로 운영하지 않는다. UI 문구와 콘텐츠 번역만 지역화한다.
- 번역이 누락되면 영어 콘텐츠를 임의 생성하거나 출처명을 식물명으로 사용하지 않는다. 번역 누락을 검사 실패로 처리한다.
- 기존 /en/ 주소로 들어오는 사용자는 대응하는 동일 식물의 단일 화면으로 연결하되 기존 검색 유입을 보호한다.

## 현재 확인된 기술 부채 (2026-10-13)
- scripts/generate_en_pages.py 가 /en/plant/<id>/index.html을 별도로 생성한다.
- scripts/generate_static_pages.py 는 한국어 상세페이지의 영어 버튼을 /en/plant/<id>/ 로 연결한다.
- language-toggle.js 는 식물 상세페이지에서 lang=en일 때 /en/plant/ 로 이동한다.
- detail-locale-history.js 는 상세페이지 언어 링크 클릭 시 location.replace를 사용한다.
- 영어 생성 코드에서 식물명 변수와 출처명 변수 충돌이 발생했으며, 생성된 HTML의 동기화 검사가 실패한 이력이 있다.

## 완료 판정 기준
1. 한국어 상세페이지에서 English를 누르면 URL이 같은 식물 식별자를 유지하고 페이지 본문이 번역된다. 한국어로 다시 바꾸면 원문이 복구된다.
2. 두 언어에서 같은 식물의 등급·근거 ID·출처 URL·영양 수치·이미지·정보 섹션이 완전히 동일하다.
3. 홈·전체 식물·상세페이지·가이드의 버튼과 내용이 모두 번역되고 기능한다.
4. 언어 전환으로 이전 기능이나 디자인이 회귀하지 않으며 모바일 레이아웃도 유지된다.
5. 기존 영어 URL의 호환성/SEO를 확인하고, 자동화 검사 전체 통과 후에만 병합·배포한다.

## 이행 순서
- 기존 한국어 상세페이지의 공통 구조를 기반으로 번역 가능한 필드와 변하지 않는 사실 필드를 분리한다.
- 공통 렌더러/공통 데이터에서 한국어와 영어 표시를 구현한다. 별도 영어 상세 HTML 생성은 제거하거나 동일 페이지로 호환 이동 처리한다.
- 언어 전환을 별도 상세페이지 이동이 아닌 동일 화면의 로케일 상태 변경으로 전환한다.
- 양방향 언어 전환 및 수치·판정·근거 일치 회귀 검사를 추가하고 기존 URL/검색 유입을 검증한다.

이 문서는 계획/검증 계약이며, 현재 구현 완료를 의미하지 않는다.

## 2026-10-15 검증 결과와 조치 (PR #303)
- PR #303은 `/en/plant/<id>/`를 noindex 리디렉션으로 바꾸고, 한국어 상세페이지에서 `language-toggle.js`의 고정 문구 사전으로 같은 화면을 번역하도록 했다.
  브라우저 검증 결과 `/plant/dandelion/?lang=en`에 한글 232단어가 남았고(main의 영어 페이지는 0단어), 문서 제목은 홈 제목("Can my tortoise eat this plant?")으로 바뀌었다.
  고정 문구 사전은 식물별 판정·근거·영양 문장을 번역하지 못하므로 완료 판정 기준 1·2를 충족하지 못한다.
- 같은 변경으로 sitemap.xml에 noindex 리디렉션 URL 182개가 `<loc>`와 hreflang 대체 링크로 남았고, `<title>`·description이 없는 페이지가 생겨
  `audit_core_page_assets`, `audit_global_seo_indexability`, `audit_language_switch_links`, `qa_detail_language_navigation`이 실패했다.
  마지막 커밋(07b20b5c)은 봇 커밋이라 CI가 승인 대기(action_required)로 실행되지 않았다.
- 조치: 식물 상세의 언어 라우팅만 main의 방식으로 되돌렸다. `/en/plant/<id>/`는 `strings_en.json`으로 번역한 완전한 영어 페이지이며,
  한국어 페이지와 hreflang 쌍으로 연결된다. 언어 전환은 같은 식물 ID를 유지하고(`/plant/<id>/` ↔ `/en/plant/<id>/`), 두 언어의 등급·근거 ID·출처 URL·
  영양 수치·이미지·섹션 순서·영양 참고자료 카드가 같은지 `qa_english_site_v1.py`가 검사한다.
  PR #303의 나머지 변경(영양 참고자료 표시, 급여 부위가 일치하지 않는 사진 제외)은 유지하고 영어 페이지에도 같은 규칙을 적용했다.
- 같은 화면 로케일 전환(이행 순서 3)은 정규 페이지가 식물별 문장의 영어 번역을 함께 담을 수 있게 된 뒤에만 다시 시도한다.
  그 전에는 리디렉션 스텁이 영어 번역 페이지를 대신하면 `qa_english_site_v1.py`가 실패한다.
