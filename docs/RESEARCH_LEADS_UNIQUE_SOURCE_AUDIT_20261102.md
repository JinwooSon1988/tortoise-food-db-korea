## 필수 품질 게이트

1. **고유 논문 수**와 **식물-논문 연결 수**를 별도로 공개한다.
2. 제목에 육지거북·먹이 단어가 있다는 이유만으로 실제 해당 식물의 급여가 확인됐다고 주장하지 않는다.
3. 원문에서 실제 식물 학명, 부위, 섭취·급여 관찰 여부, 대상 육지거북 종을 확인하기 전에는 안전성 등급을 부여하지 않는다.
4. 동일 논문을 여러 식물에 연결한 경우 식물별 본문 근거 위치를 확인한다.
5. 커뮤니티 주장은 별도 표시하며 학술적 안전성 입증으로 취급하지 않는다.
6. 키워드 부재는 관련성 부재의 증거가 아니므로 자동 삭제하지 않는다.

**상태:** 후보 데이터 정량 감사 완료. 582개 고유 문헌의 원문 내용·식물별 적용성 검증은 미완료.
