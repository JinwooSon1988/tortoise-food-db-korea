# Evidence expansion batch 2

This batch separates general herbivorous-reptile evidence from Mediterranean Testudo evidence.

Promoted from `⚪ 검증 미완료` to a cautious yellow supplemental card:
- bok choy
- collard greens
- cabbage

Basis: Merck Veterinary Manual lists these among calcium-rich plant foods for plant-eating reptiles. This is not direct Mediterranean Testudo feeding evidence, so the UI explicitly labels applicability as general herbivorous-reptile evidence and does not treat these foods as staples.

Safety rule: general reptile evidence may support a supplemental-use card, but never a Mediterranean Testudo direct-evidence claim.
