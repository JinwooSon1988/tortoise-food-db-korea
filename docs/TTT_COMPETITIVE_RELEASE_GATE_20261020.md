# TTT 경쟁 우위 실행 기준 — 2026-10-20

## 사용자에게 보여줄 결과의 우선순위
1. **정확히 어떤 식물인가?** 학명, 동의어, 종/속/품종 식별 범위와 검증된 사진.
2. **육지거북에게 먹여도 되는가?** A–D 판정 또는 **급여 안전성 미확정**을 첫 화면에 표시.
3. **어느 부위인가?** 잎, 꽃, 줄기, 열매, 씨앗, 뿌리를 구분하고 서로 다른 판정을 합치지 않는다.
4. **왜 그런가?** 근거 유형(직접 섭식/사육 지침/영양 분석/독성/분류), 해당 육지거북 종, 연구 대상과 한계, 원문 URL.
5. **무엇을 해야 하는가?** 급여 가능 부위·제한사항·확인할 사항을 간결히 안내.

## 규모와 정확성
- 현재 검증된 공개 마스터: `data/plants.json` 182개 (2026-10-20 확인).
- 목표: 검색 가능한 분류학적 식물 10,000종 이상. **분류만 확인된 식물은 안전성 미확정으로 분리**.
- 10,000개가 모두 안전한 먹이 또는 근거가 검증된 식물이라는 인상을 주지 않는다.
- 속 수준(`spp.`) 항목과 종 수준을 같은 '종 수'로 계산하지 않는다. 동의어·아종 중복 제거.
- 공식 식물 분류 데이터 원본의 라이선스/출처/버전을 기록하고, 외부 DB의 설명·사진·급여 판정을 무단 복제하지 않는다.

## The Tortoise Table 실제 화면에서 확인된 벤치마크
- 카테고리별 진입, A–Z 탐색, 꽃 색상 탐색.
- 카드에 사진, 일반명, 학명, 급여 등급 동시 표시.
- 등급 필터 및 부위별 설명. 보리(Hordeum spp.)의 잎과 곡물을 구분.
- 한 식물에 여러 사진.
- 원본: https://www.thetortoisetable.org.uk/plant-database/
- 원본 예시: https://www.thetortoisetable.org.uk/plant-database/viewplants/?plant=589&c=2
- 이는 경쟁 기능 벤치마크이며 TTT의 콘텐츠나 이미지 사용 권한을 의미하지 않는다.

## 릴리스 게이트
- 기존 182개 등급/원문 연결 변경 없음.
- 신규 식물별 정확한 분류 출처 식별자 필수.
- 미확정 상태가 A–D 안전 판정처럼 렌더링되지 않아야 함.
- 한국어/영어 검색과 상세 화면의 동일 ID 연결.
- 10,000종 규모에서도 검색 성능과 모바일 반응성 검사.
- 실제 등록 수, 급여 판정 완료 수, 급여 근거 연결 수, 분류만 확인된 수를 별도 보고.
