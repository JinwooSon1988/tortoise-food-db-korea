# 대규모 식물 목록 공개 계약 (2026-10-16)

## 목적
기존 182종의 검증된 급여 판정을 변경하지 않고 전 세계 식물 분류 후보를 별도 공개 목록으로 수용한다. GBIF 후보 9,995종은 **먹이 9,995종이 아니다**.

## 필수 레코드
```json
{"taxon_id":"gbif:123","scientific_name":"Genus species","rank":"SPECIES","source":"GBIF","source_taxon_url":"https://www.gbif.org/species/123","identity_status":"taxonomy_candidate","feeding_evidence_status":"not_found_or_not_reviewed","feeding_safety_status":"not_assessed","evidence":[]}
```

## 공개 규칙
1. taxonomy_candidate 레코드는 **식물 목록**에 노출 가능. 기존 급여 판정 검색 결과와 혼합하지 않는다.
2. '급여 근거 미확인'은 '먹이면 안 됨' 또는 '안전함'과 다르다.
3. 섭식 기록이 있는 경우 거북 종·식물 학명·부위(불명 가능)·관찰 방식·DOI/URL·원문 위치·검토 상태를 함께 표기한다.
4. 원문 발췌 자동 추출은 '검토 전 후보'로만 표시. 학명 정규식 일치만으로 섭식 기록이라 주장하지 않는다.
5. 사육자 커뮤니티/전문기관/야생 관찰/영양/독성 자료는 서로 다른 근거 유형으로 공개하며 안전성 등급 A/B/C/D를 자동 생성하지 않는다.
6. 기존 data/plants.json, data/public_assessments.json, 정적 182개 상세 페이지 및 SEO는 그대로 유지한다.
7. 후보 대량 페이지의 자동 검색엔진 색인은 보류한다(noindex). 식물 동정·근거가 검토된 경우에만 별도 색인 검토한다.
8. 신규 후보의 한국어·영어 표시는 모두 제공하고, 한국어 통용명이 없는 경우 학명을 사용한다. 임의 번역명을 만들지 않는다.

## 배포 차단 조건
기존 182종 판정 변경, 후보에 A/B/C/D 자동 부여, 야생 섭식과 사육 안전성 혼동, 식물 아닌 학명 포함, 출처 링크 누락, 중복 학명/동의어 무처리, 대량 렌더링 성능 회귀.

## 현황
GBIF 후보 약 9,995건은 이전 수집 결과의 수치이며 이 커밋에 해당 9,995건 원본 데이터가 포함됐다는 뜻이 아니다. 데이터 실물 확보 후 파싱·중복 제거·검증을 거쳐 별도 커밋으로 추가한다. 이 문서는 배포나 병합 승인이 아니다.
