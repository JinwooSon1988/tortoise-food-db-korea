# 급여 판정 충돌 편집 검토 — 2026-10-09

## 범위
현재 공개 `data/public_assessments.json`의 식물별 판정과 근거 설명을 대조한 **편집 검토**다. 원자료를 새로 검증한 독립적인 독성평가가 아니며, 판정 등급은 이 문서에서 변경하지 않는다.

## 1. 파프리카·피망 과실 (bellpepper) — 우선 재검토
- 현재 공개 판정: `limited_supplement`.
- 같은 공개 설명에서 육지거북 전문 식물 DB가 과실을 **급여하지 않음**으로 분류한다고 인정한다.
- 반대 방향의 논거로 제시한 Eggink 2012는 **과실 식물화학 연구**이지 육지거북의 섭식·독성·장기 안전성 연구가 아니다.
- 따라서 해당 식물화학 연구만으로 전문 급여 비권장 의견을 뒤집을 수 있는지는 **입증되지 않았다**. 독성 용량 미제시가 곧 급여 안전성 입증도 아니다.
- **편집 판단:** 현재 C등급을 확정된 안전 권고처럼 표현해서는 안 된다. 직접 급여 연구 또는 적합한 수의·전문 근거가 확보되기 전에는 재검토 대상으로 표시하고, 사용자에게 전문자료와의 충돌을 판정 바로 옆에서 명시하는 방안을 검토한다.

## 2. 복숭아잎 (peachleaf)
- 현재 공개 판정: `limited_supplement`.
- 잎 추출물 연구는 **신선한 잎을 거북에게 급여한 실험이 아님**. 추출물의 세포독성이나 생물학적 작용을 그대로 급여 위해로 해석해서는 안 된다.
- 복숭아 과실·씨앗·핵 등 다른 부위로 잎의 판정을 확장하지 않는다.

## 3. 단풍나무잎 (mapleleaf)
- 현재 공개 판정: `limited_supplement`.
- `Acer spp.` 수준의 전문 식물 DB 의견을 특정 단풍나무 종 전체의 직접 안전성 증거로 바꾸지 않는다.
- 잎 외 씨앗·수피로 적용하지 않는다.

## 4. 달리아 (dahlia)
- 현재 공개 판정: `limited_supplement`.
- 전문자료는 **잎·꽃**과 **뿌리·괴경**을 구별한다. 뿌리·괴경에 대한 비급여 권고를 잎·꽃에도 무차별 적용하지 않는다.
- 반대로 잎·꽃의 제한적 허용을 뿌리·괴경으로 확대하지 않는다.

## 후속 작업의 완료 조건
1. 파프리카의 전문 비권장 근거와 식물화학 연구가 답하는 질문을 분리해 근거 수준을 재판정한다.
2. 급여 권고를 변경할 때에는 원문 출처·적용 부위·대상 거북·불확실성을 함께 기록한다.
3. 실제 사용자 화면에서 상충 근거를 숨기지 않고, 짧은 핵심 설명 뒤에 상세 근거를 제공한다.
4. 자동 QA는 판정 등급을 임의로 고정하지 않고 부위·범위·근거 누락을 감지한다.
