# Naver Blog → 거북밥 전환 퍼널 v1

목표는 네이버 검색 방문자가 글을 읽고 끝나는 것이 아니라 거북밥에서 자신의 먹이를 직접 확인하고, 오늘 식단 기능까지 이어가게 하는 것이다.

## 기본 구조

1. 제목은 `육지거북 + 먹이명 + 실제 질문`을 우선한다.
2. 첫 화면에서 질문에 대한 결론을 먼저 제시한다.
3. 본문에서 판정의 근거 수준과 적용 범위를 설명한다.
4. 중간 CTA는 `?q=먹이명` 검색 딥링크를 사용해 거북밥의 실제 판정을 즉시 보여준다.
5. 상세 출처가 필요한 독자는 canonical plant page로 연결한다.
6. 글 말미에는 거북밥의 `오늘 뭐 먹일까?` 기능을 안내해 재방문 이유를 만든다.

## CTA 원칙

- `안전`, `매일`, `주식`, `무제한` 같은 표현은 DB 판정이 직접 지지하지 않으면 앵커에 쓰지 않는다.
- `급여 근거 확인`, `제한적 급여 근거 확인`, `판정 보류 근거 확인`처럼 실제 DB 판정 강도를 보존한다.
- 아욱처럼 식물동정이 해결되지 않은 항목은 승인형 CTA로 바꾸지 않는다.
- 야생 섭식 빈도를 사육환경의 급여 비율로 변환하지 않는다.

## 글 템플릿

- 제목: `[먹이명], 육지거북에게 먹여도 될까?`
- 도입: 독자가 검색한 질문을 2~3문장 안에 그대로 답한다.
- 핵심: `현재 거북밥 판정 / 적용 범위 / 가장 중요한 제한점`을 짧게 제시한다.
- 근거: 출처 종류와 직접성 차이를 설명한다.
- CTA 1: `[먹이명] 육지거북 급여 근거 바로 확인` → `/?q=[먹이명]`
- 실전: 단독·매일 급여 여부보다 다양한 식단 안에서 어떤 역할인지 설명한다.
- CTA 2: `오늘 뭐 먹일까?` → `/today/`
- 말미: 식물 동정과 종별 적용범위 주의 문구를 둔다.

## 우선 적용 글

1. 치커리와 근대, 매일 줘도 될까? 근거 수준부터 다르다.
2. 콘샐러드(램스레터스), 육지거북에게 먹여도 될까?
3. 민들레·질경이·뽕잎 중 육지거북 먹이 근거가 가장 강한 것은?
4. 아욱은 육지거북 먹이로 안전할까? 이름만 보고 판단하면 안 되는 이유.
5. 육지거북 먹이 69종, 이름만 검색하면 근거 수준까지 확인하는 방법.

복사용 실제 URL과 판정 강도를 보존한 앵커는 `data/blog_search_links_v1.json`을 단일 기준으로 사용한다.
