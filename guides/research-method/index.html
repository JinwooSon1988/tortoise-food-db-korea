EVIDENCE & REVIEW

거북밥은 어떻게 판정하는가?

검색 결과의 A·B·C·D는 ‘인터넷에서 많이 먹인다는 말’을 단순히 모은 등급이 아니다. 식물의 정확한 정체성, 실제 확인된 식물 부위, 근거가 다루는 동물 분류군과 자료의 성격을 분리해 검토한 뒤 공개한다.

1. 식물부터 정확히 확인

학명과 분류계급을 우선 확인한다. 종을 확정할 수 없는 자료를 다른 종의 대표 이미지나 근거로 조용히 치환하지 않는다.

2. ‘무슨 부위인가’를 분리

잎·꽃·열매·뿌리·씨앗 등은 서로 같은 급여 근거로 자동 취급하지 않는다. 사진과 급여 대상 부위가 다르면 상세페이지에서 그 차이를 표시한다.

3. 근거의 적용 범위를 확인

육지거북 직접 자료, 전문 사육자료, 근연 분류군 자료, 일반 초식 파충류 자료, 식물 성분·독성 자료를 같은 무게로 섞지 않는다. 어떤 자료가 무엇을 말할 수 있는지 함께 표시한다.

4. 근거가 약하면 약하다고 표시

야생에서 먹었다는 관찰은 ‘자연에서 섭식됐다’는 사실을 보여줄 수 있지만 사육장에서의 권장 급여 비율을 자동으로 결정하지 않는다. 근거 부족을 안전하다고 해석하지 않는다.

판정의 핵심

직접 근거가 가장 강한가? → 대상 거북과 식물을 실제로 다룬 자료인지 확인한다.

다른 자료라면 무엇을 보완하는가? → 수의학·전문 사육·야생생태·식물학·성분 자료의 역할을 구분한다.

무엇을 아직 모르는가? → 확인되지 않은 종·부위·용량·장기 영향은 확정된 사실처럼 쓰지 않는다.

근거 확실성은 급여 등급과 다르다

급여 등급(A·B·C·D)은 얼마나 먹여도 되는지를 나타낸다. 근거 확실성은 그 판정을 뒷받침하는 자료가 얼마나 직접적이고 충분한지를 나타낸다. 예를 들어 급여 등급이 D여도 근거 확실성은 ‘낮음’일 수 있다. 이 경우는 위험이 입증됐다는 뜻이 아니라, 확인된 근거 범위에서 보수적으로 판정했다는 뜻이다.

표시 단계 높음 → 다소 높음 → 중간 → 중간 이하 → 다소 낮음 → 낮음 → 매우 낮음. 근거가 아직 정리되지 않았으면 ‘미확정’으로 표시한다.
