# 대량 식물 조사 입력 규격 (v1)

이 파일은 **공개 데이터가 아닌 조사 대기열**의 입력 규격이다. 예시는 실제 검증된 식물이나 근거가 아니므로 절대 운영 사이트로 가져오지 않는다.

## 작업 흐름
1. 식물의 학명·과명·국문/영문 이름을 식물분류학 출처에서 검증한다. 학명이 같은 품종·이명·상업명을 중복 페이지로 만들지 않는다.
2. 전 세계 학술자료, 수의·동물원 사육지침, 전문 사육자료, 관찰기록을 각각 **출처 URL·정확한 주장·식물 부위·대상 거북 분류군·한계**와 함께 기록한다.
3. 조사 후보는 `research_only` 또는 `review_required`로만 저장한다. **출처가 있다는 이유만으로 급여 안전성이나 등급을 추론하지 않는다.**
4. 별도 검토자가 학명/부위/대상 종/금기/오염·독성 정보를 확인한 뒤 기존 `public_assessments.json` 구조에 근거 ID와 판정 사유를 연결한다.
5. 영양정보는 검증된 경우에만 수치를 기재한다. 결측은 `not_linked`, 참고만 가능하면 `reference_only`로 유지한다.
6. 기존 페이지 생성 및 영문 번역 QA 통과 후 별도 배포 승인을 받는다.

## 일괄 검증
`python scripts/validate_bulk_plant_intake.py research/intake_batches/BATCH.json`

## 주의
- 템플릿의 example.org 링크는 자리표시자이며 실제 출처가 아니다.
- 웹페이지/커뮤니티 관찰은 기록할 수 있지만 학술적 안전성 입증으로 표기하지 않는다.
- 원문이 속(Genus)만 다루면 특정 종(species) 전체에 자동 확대 적용하지 않는다.
- 일부 부위의 관찰 기록을 잎·줄기·꽃·열매 전체로 일반화하지 않는다.
- 조사 후보와 검토 완료 공개 페이지는 별도 계층이다.
